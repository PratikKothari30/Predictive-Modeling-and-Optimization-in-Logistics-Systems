# Predictive-Modeling-and-Optimization-in-Logistics-Systems

This report presents the final phase of an end-to-end data analytics initiative aimed at transforming diesel generator (DG) set dispatch operations. Designed to seamlessly integrate with prior findings—ranging from initial strategic alignment and robust data preprocessing to comprehensive exploratory analysis—this deliverable operationalizes predictive modeling and mathematical optimization to tackle complex supply chain challenges.  The core focus of this document centers on forecasting critical operational metrics, specifically the total order-to-dispatch cycle time, while simultaneously addressing outbound logistics inefficiencies. 

By establishing an enhanced 1,000-record dataset that reflects multi-source factory dispatches and regional distribution demands, the report evaluates three regression models—Multiple Linear Regression, Decision Trees, and Random Forests—to identify key bottlenecks such as payment authorization lags and order volume constraints. It details the full machine learning workflow, including feature engineering via scikit-learn pipelines, cross-validation, and hyperparameter tuning, proving that an ensemble Random Forest approach provides superior predictive accuracy.  

Beyond cycle-time prediction, the report incorporates a operational Linear Programming framework designed to optimize outbound transport allocation. By balancing factory capacity limits against regional dealer demand, the optimization strategy yields a quantifiable 12.5% reduction in total logistics expenditure. The document concludes with actionable recommendations for ERP system integration, automated financial authorization workflows, and periodic model recalibration to sustain long-term supply chain efficiency.
